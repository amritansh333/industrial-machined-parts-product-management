# Industrial Machined Parts Product Management

A responsive web application for showcasing industrial machined plastic parts and engineering components.

## Features

- Product showcase interface
- Product image slider
- Technical characteristics section
- Product specifications table
- Applications overview
- Responsive design
- Modern industrial UI

## Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Installation

Clone repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build project:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
